### Database Architecture
1. **Multi-tenant design** - B2B, B2C, B2E from day one
2. **Component-based documents** - 52 reusable document types
3. **Dynamic form system** - Country-specific additional questions
4. **ML-powered validation** - Passport OCR + face recognition (15 checks)

6. **Premium tier system** - Atlys Black (2x price, 6x faster)
7. **Multi-country visas** - 1 visa valid for 7 countries
8. **Gamification** - Visa awards with user voting

### Tech Stack Identified
**Frontend**: React/Next.js + TipTap (rich text)  
**Backend**: Node.js + PostgreSQL + Redis  
**ML/AI**: OpenCV + Tesseract OCR + TensorFlow  
**Infrastructure**: Cloudinary + AWS + Cloudflare  
**Payments**: Razorpay + Stripe

### Feature Highlights
1. **Atlys Black**: Premium tier with 60-100% markup, express processing
2. **Visa Awards**: Gamification with user votes (912 votes for Japan)
3. **Multi-country**: Japan visa valid for KR, VN, MY, SG, JO, MN

5. **Add-on ecosystem**: eSIM (₹443-₹1065), insurance, city selection (₹7,500)
6. **Family applications**: Batch processing with auto-fill
7. **Risk scoring**: Pre-qualification checks (expired passport, funds, criminal record)

## 💡 Insights for Our Platform

### What We'll Copy:
1. **Component-based document system** → Reusable across visa types
2. **Dynamic additional questions** → Country-specific forms
3. **Transparent fee breakdown** → Build trust
4. **Family application support** → Key differentiator

### What We'll Do Better:

4. **India-first focus** → Aadhaar, PAN, ITR support
5. **Clear pricing** → No hidden VFS fees

### What We'll Skip (For Now):

2. **50+ dev options** → Start with 10 essential
3. **Custom ML models** → Use AWS initially
4. **B2E portal** → Focus B2C first
5. **Complex rich text** → Markdown for MVP

## 🛠️ Technical Decisions Made

### 1. Use Drizzle ORM (Not Prisma)
**Why**: Simpler migrations, better TypeScript, faster queries

### 2. AWS Services Over Custom ML
**Why**: Faster to market, managed scaling
- AWS Textract → Passport OCR
- AWS Rekognition → Face validation
- AWS S3 → Document storage

### 3. Tailwind CSS (Confirmed)
**Why**: Portrait design system maps perfectly to utility classes

### 4. Markdown Over Rich Text Editor
**Why**: Simpler for MVP, can upgrade to TipTap later
