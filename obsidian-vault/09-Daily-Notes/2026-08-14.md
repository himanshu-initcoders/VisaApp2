## 💡 Ideas & Notes

### Architecture Decisions
- **Next.js 16 App Router**: Using server components by default for better performance
- **Drizzle ORM**: Chosen over Prisma for better TypeScript integration and performance
- **NextAuth v5 (beta)**: Using latest version for better Next.js 15+ integration
- **Tailwind CSS**: Implementing complete Portrait design system with custom configuration
- **Zod**: Type-safe validation for forms and API inputs
- **S3 for uploads**: Direct S3 upload with presigned URLs to avoid server load

### Design System Implementation
- Created comprehensive Tailwind config with Portrait colors
- Added custom font sizes with correct letter spacing
- Configured border radius values (nav: 28px, card: 24px, input: 16px)
- Added custom shadows for floating nav and cards
- Created rainbow gradient for primary CTA

### Database Schema
- Users table with role-based access control (user, admin, reviewer)
- Separate tables for visa applications and passport services
- Documents table with S3 references and verification status
- Payments table with status tracking
- Status history for audit trail
- All tables use UUID primary keys
- Timestamp tracking on all records

### Security Considerations
- Password hashing with bcrypt (12 rounds minimum)
- Environment-based secrets
- S3 presigned URLs with expiry
- File type and size validation required
- RBAC implementation needed
- Input validation on all forms (client + server)

## 📚 Learnings

### Next.js 16
- App Router is now stable and recommended
- Server components by default improve performance
- Server actions simplify form handling
- File-based routing is intuitive

### Drizzle ORM
- Migration workflow is straightforward (generate → review → migrate)
- Type inference is excellent
- Better performance than Prisma for complex queries
- Schema-first approach works well

### Portrait Design System
- Deep navy ink (#08304c) is primary text color
- Rainbow gradient should ONLY be used for:
  1. Primary CTA button border
  2. One italicized word per headline
  3. Small decorative accents
- Button radius (28px) is intentionally larger than card radius (24px)
- Switzer for body (10-24px), Basier Circle for headlines (31px+)
- Negative letter spacing on headlines creates sculptural effect

### Project Organization
- Obsidian vault helps maintain comprehensive documentation
- Linking notes creates knowledge graph
- Daily notes track progress and decisions
- Templates ensure consistency
