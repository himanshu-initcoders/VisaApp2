## Decisions made
- Files: IndexDB during apply; cloud only after mock pay/submit
- Cloud path: `applications/{countryCode}/{listingId}/{userId}/{applicationId}/passengers/{passengerId}/{slotKey}.{ext}`
- Applicants: mobile OTP (mock always passes); admins: email/password on `/login`
- DB application row created on submit only; skip payments table until real gateway
- Form versions: explicit Publish + pointer + snapshot on application
- Multi-passenger: one row, travellers JSON
- Post-submit docs: admin replace only (delete old cloud object); applicants read-only
- After login: sync draft JSON to server; files stay IndexDB until submit (re-upload on new device)
- Admin date filters use IST day bounds; CSV hard-capped at 5000 rows
