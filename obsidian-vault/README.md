## 📝 How to Use

### Adding New Notes
1. Create note in appropriate folder
2. Add frontmatter (optional but recommended)
3. Link to related notes with `[[Note Name]]`
4. Add tags at bottom: `#tag1 #tag2`

### Templates
Use templates from `08-Templates/` for consistency:
- Feature planning → `📝 Feature Template.md`
- Bug tracking → `🐛 Bug Template.md`
- Daily logs → `📅 Daily Note Template.md`

### Linking Strategy
- **Internal links**: `[[Note Name]]` or `[[Note Name|Display Text]]`
- **Section links**: `[[Note Name#Section]]`
- **External links**: `[Text](URL)`

## 🎯 Second Brain Philosophy

This vault follows the **PARA method** loosely:
- **Projects**: Active work (Features, Development)
- **Areas**: Ongoing responsibilities (Design System, Tech Stack)
- **Resources**: Reference material (Resources Library, Competitor Analysis)
- **Archives**: Completed work (move here when done)

### Key Principles
1. **Atomic notes**: One idea per note
2. **Linked thinking**: Connect related concepts
3. **Progressive summarization**: Bold key points, highlight insights
4. **Evergreen notes**: Update notes as knowledge evolves
