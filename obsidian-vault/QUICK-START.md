# 🚀 Quick Start Guide

Welcome to your Visa & Passport Service Second Brain!

## 1️⃣ Open in Obsidian

1. Download [Obsidian](https://obsidian.md/) if you haven't already
2. Open Obsidian
3. Click "Open folder as vault"
4. Select: `d:\Visa\obsidian-vault`

## 2️⃣ Your First Steps

### Start Here
Open [🏠 Home.md](00-Index/🏠%20Home.md) - your main navigation hub

### Understand the Project
1. Read [[📋 Project Overview]] to understand vision and goals
2. Review [[🏆 Competitor Analysis]] to see how we differentiate from Atlys
3. Study [[🎨 Design System Hub]] to learn the Portrait design language

### Start Building
1. Check [[⚙️ Technical Stack]] for tech requirements
2. Review [[🔧 Features Roadmap]] for development priorities
3. Understand [[👤 User Personas]] and [[📊 User Flows]]

## 3️⃣ Navigation Tips

### Finding Notes
- Use `Ctrl/Cmd + O` to quick-open any note
- Use `Ctrl/Cmd + P` for command palette
- Click any `[[WikiLink]]` to jump to related notes

### Creating Notes
- Use templates from `08-Templates/` folder
- Link notes with `[[Note Name]]`
- Add tags at bottom: `#tag1 #tag2`

## 7️⃣ Key Principles

### For This Project
- Target: Indian citizens only
- Services: Visa + Passport services
- Goal: Better than Atlys in UI/UX
- Design: Portrait system (warm, personal, scrapbook)
- Tech: Next.js 16 + Postgres + Drizzle + S3

### For the Vault
- **Link everything** - Build a web of knowledge
- **Update, don't duplicate** - Keep notes evergreen
- **Use templates** - Maintain consistency
- **Tag appropriately** - Enable discovery
- **Review regularly** - Keep knowledge current
