# 📋 Project Overview

## Vision
Build the most user-friendly visa and passport service platform for Indian citizens, surpassing competitors in both UI/UX and service quality.

## Target Market
- **Geography**: India (Indian citizens only)
- **Services**: 
  - Visa applications for international travel
  - Passport services (new, renewal, updates)

## Core Differentiators vs Atlys
1. **Design Language**: [[🎨 Design System Hub|Portrait design system]] - warmer, more personal, scrapbook aesthetic
2. **User Experience**: Simplified workflows with better guidance
3. **Speed**: Faster processing and application tracking
4. **Transparency**: Clear pricing and timeline expectations

## Success Metrics
- **Primary**: Application completion rate
- **Secondary**: Time to complete application
- **Tertiary**: Customer satisfaction (NPS)
