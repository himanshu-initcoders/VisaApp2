- ✅ 4 visa process types (eTA, physical sticker, e-visa, appointment)
- 💎 Premium "Atlys Black" tier (2x price, 6x faster)
- 🎮 Gamification (visa awards with user voting)
- 🌍 Multi-country visas (1 visa for 7 countries)
- 💰 Transparent pricing (₹0 - ₹18,200 per visa)
- 📱 57 occupation types, Aadhaar + PAN support
- 🏗️ 18 database tables identified
